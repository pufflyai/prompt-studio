# SDK cookbook

The [workbench cookbook](../../extensions/cookbook.md) is the authoring guide for editable resource pages, inspectors, shared mode panels, editor collections, cross-extension navigation, and webview lifecycle.

Use the [SDK package guide](../../../../packages/sdk/README.md) for installation and entry points. Use [Extension Lab](../../../../extensions/extension-lab/README.md) as executable source. Its TypeScript modules are compiled and installed through the same public workflow as other extensions.
