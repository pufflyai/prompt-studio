# SDK

Use `@pstdio/sdk` for public TypeScript integration. The [package guide](../../../../packages/sdk/README.md) lists supported entry points and installation requirements.

Extension authors should start with the [workbench cookbook](../../extensions/cookbook.md) and [Extension Lab](../../../../extensions/extension-lab/README.md). These examples use public contracts for editing, persistence, inspectors, shared mode panels, and navigation.

Host authors should use the [workbench guide](../../../../packages/pstdio-workbench/README.md). Host registries and layout controllers are not extension authoring APIs.
