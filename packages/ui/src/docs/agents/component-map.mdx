# Component Map

Use this map to choose the first component to inspect through Storybook MCP.

## Inputs

- Chakra recipe-backed `Button`, `Input`, `Textarea`, `Menu`, `Popover`, `Field`, and `InputGroup` are valid public
  building blocks when their styling comes from `psTheme`.
- `Checkbox`, `Radio`, `Switch`, and `Slider` cover package-owned controls with local behavior or styling beyond Chakra defaults.
- `ParamEditor` and `TagEditor` cover structured editing flows.
- Use icon buttons for compact tool actions and provide accessible labels.

## Navigation and lists

- `Breadcrumb` handles hierarchical page context.
- `Tabs` handles dense in-surface navigation; tab triggers should stay at `xs` density.
- `SearchableMenu` handles filtered action and selection menus.
- `ColumnFileBrowser`, `Sidenav`, `TreeList`, and `ListRow` cover navigable resource structures.
- Use `TreeList` for hierarchical sections and `ListRow` for individual row composition.

## Data display

- `DataTable` handles tabular data.
- `DataRenderer` handles switchable board/list data views with filtering, grouping, and ordering.
- `Avatar`, `DataRendererCard`, `DataRendererList`, `ResourceBadge`, `WorkspaceBadge`, `InfoCard`, and `Activity` cover common data surfaces.
- Use `Foundations/Component Gallery / Composites` for advanced examples before composing `DataRenderer`, `ParamEditor`, or `Activity` from scratch.

## Feedback and overlays

- `AlertMessage`, `EmptyState`, `SessionIndicator`, and `Toaster` cover status and feedback.
- `DeleteConfirmationModal`, `Palette`, and `RepoPickerDialog` cover overlay interactions.

## Text and agent UI

- `MarkdownEditor`, `PromptEditor`, `RichMessage`, and collaborative editor stories cover rich-text surfaces.
- `ChatPanel`, `ChatInput`, `ChatMessage`, `ChatPrimitives`, `AttachmentList`, and `ToolInvocationTimeline` cover agent conversation UI.
