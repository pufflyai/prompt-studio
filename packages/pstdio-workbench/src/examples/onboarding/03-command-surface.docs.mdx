# 3. Open Your Widget From A Button

To put a button in the main header, register a command with the open-widget
logic, then add a menu item that references the command id. Adding the same
command id to the command palette path makes it searchable too — no extra
handler.

<Canvas of={OnboardingStories.CommandAndMenu} sourceState="shown" />

This is the pattern for almost every user-triggered action in the workbench:
**register a command, attach it to as many surfaces as you need by id.** Don't
call your handler directly from button `onClick`s — that breaks keybindings,
context-key gating, and the palette later on.

The story starts on the placeholder so you can see the header button open the
widget. Press ⌘P / Ctrl+P to open the palette and try the same command from
there.
