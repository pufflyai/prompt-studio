# 10. Add A Data Workspace

If you need a Notion/Linear-style data view — sortable, filterable, with board
and list layouts — register a **kanban renderer** instead of a plain renderer.

<Canvas of={OnboardingStories.KanbanRenderer} sourceState="shown" />

You provide:

- The **schema** — tag definitions, the fields users can group/sort/filter by,
  the display properties they can toggle on cards.
- An **`executeQuery({ settings, filters })`** that returns rows. Return all
  rows for simple cases; push the filter down to your backend when it matters.
- Row-mutation callbacks for click, drag, tag change, etc.

Like the tree renderer, `registerKanbanRenderer` auto-creates a Panel renderer
with the same id; you place it with `layout.registerPanel` and open it the
usual way.
