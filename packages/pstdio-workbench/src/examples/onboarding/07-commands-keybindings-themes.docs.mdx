# 7. Add Keyboard Shortcuts And Themes

Two extras that come up on most workbenches:

**Keybindings** bind a key chord to a command id. Same command pattern as
story 3 — once a command is registered, attach a keybinding with
`keybindings.registerKeybinding({ commandId, keybinding: "mod+k" })`. The
workbench dispatches it when the chord fires, no extra handler needed.

**Themes** come from the workbench-owned `WorkbenchThemeProvider`, which composes
the shared `@pstdio/ui` theme preference system. Use the built-in
`workbench.action.changeTheme` command to open the same theme picker as the
dashboard. Extension color themes can provide VS Code-compatible color tokens
for the workbench chrome, while contributed views should use Chakra/UI tokens.
