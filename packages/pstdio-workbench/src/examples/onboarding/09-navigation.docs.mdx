# 9. Handle Deep Links

To support URLs or other ingress strings, register a navigation parser that
turns the string into a target the workbench knows how to dispatch.

<Canvas of={OnboardingStories.Navigation} sourceState="shown" />

A parser returns one of:

- `{ kind: "resource", resource }` — open a resource (uses your presenters from
  story 5).
- `{ kind: "panel", widgetId, region?, resource? }` — reveal a specific widget.
- `{ kind: "command", commandId, args? }` — run a command.
- `{ kind: "compound", targets }` — apply multiple targets together. If any
  one fails, the layout is rolled back, so a deep link either applies fully
  or not at all.

Then `navigation.openTarget(target)` (or `navigation.openLocation(uri)` for
strings) is the one entry point — same path regardless of who triggered it.

The story exposes each shape as buttons so you can compare the URL form
against the equivalent direct target.
