# 12. Choose Sub Panel Placement Behavior

A Location Panel is the fixed subject of a workbench location. Optional views
inside it are registered as Sub Panels, which is what makes them appear as tabs.
This story opens the same renderer through three Sub Panel placement policies.

<Canvas of={OnboardingStories.WidgetVariants} sourceState="shown" />

Use the **Variants** sidenav to open each contribution repeatedly:

- **Widget variants** is the Location Panel. It appears as the first,
  uncloseable tab while any Sub Panel is open.
- **Closable singleton** is the default Sub Panel policy: one closable placement
  per Location.
- **Resource Sub Panels** set `singleton: false`; the default
  `reuse: "resource"` gives each resource URI one tab.
- **Scratch Sub Panels** set `singleton: false` and `reuse: "none"`, so every
  open call creates a new closable placement.

The Main Panel shows the active placement id, contribution id, resource URI,
and resolved role. Reopen Alpha to select its existing tab; create Scratch Sub
Panels to see duplicate placements appear.
