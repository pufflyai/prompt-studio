# 12. Choose Widget Behavior For Plugin Panels

Plugin modules usually differ less by renderer code than by the placement
behavior they ask the workbench for. This story opens the same renderer through
four widget variants: a default singleton, a closable singleton, resource-backed
tabs, and duplicate scratch tabs.

<Canvas of={OnboardingStories.WidgetVariants} sourceState="shown" />

Use the **Variants** panel to open each contribution repeatedly:

- **Default singleton** omits `singleton`, so it gets one placement and is not
  closable by default.
- **Closable singleton** keeps one placement but opts into `closable: true`.
- **Resource tabs** set `singleton: false`; the default `reuse: "resource"`
  gives each resource URI one tab.
- **Scratch tabs** set `singleton: false` and `reuse: "none"`, so every open
  call creates a new closable placement.

The main panel shows the active placement id, contribution id, resource URI,
and resolved tab behavior. Reopen Alpha to see resource reuse activate the
existing tab; create scratch tabs to see duplicate placements appear.
