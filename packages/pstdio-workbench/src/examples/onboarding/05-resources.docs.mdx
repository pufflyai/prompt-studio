# 5. Make Tree Nodes Open Tabs

To make a tree node open a tab when clicked, give it a `resource` ref and tell
the workbench how to open that kind of resource.

<Canvas of={OnboardingStories.Resources} sourceState="shown" />

Three pieces:

- `resources.registerKind({ kind, label, icon })` — declares the type once.
- `resources.registerOpener({ canOpen, open })` — says "for resources of this
  kind, open this widget with the resource attached".
- Attach `resource: { kind, uri, label }` to each tree node.

Standard icon names for shared resource concepts:

| Concept       | Icon                      |
| ------------- | ------------------------- |
| Project       | `folder-root`             |
| Workspace     | `computer`                |
| Worktree      | `git-pull-request-draft`  |
| Ticket        | `component`               |
| Data renderer | `square-kanban`           |
| Settings      | `settings`                |

Now clicking a node calls `resources.openResource` for you, which routes
through the opener and opens a tab. Click the same node twice — the existing
tab activates instead of duplicating, because the resource URI matches.

Build your features around resources whenever there's a "thing you can open".
History and navigation both speak resource refs, so your tree rows, command
targets, and routed widgets can share the same data shape.
