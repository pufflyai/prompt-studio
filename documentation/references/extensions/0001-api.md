# Overview

Extensions use the public `@pstdio/sdk/extensions` entry point. These pages cover the manifest, contributions, and how the host runs them.

An extension's identity and supported host versions live in its `package.json`. Its entry file's default `defineExtension()` export declares its contributions.

## Getting started

Start with [extension authoring](../../guides/extensions/0001-authoring.md) and the [workbench cookbook](../../guides/extensions/0002-workbench-cookbook.md). The [smoke checks guide](../../guides/extensions/0006-smoke-checks.md) explains what `pst extensions test` covers.

The full context and contribution types live in the [extension kernel](../../../packages/pstdio-api-contracts/src/extension-kernel/index.ts) source. Import them only through `@pstdio/sdk/extensions`. Other package paths are internal and can change without notice.
