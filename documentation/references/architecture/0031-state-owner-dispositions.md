# State owner dispositions

PS-157 reviews the 50 groups audited at `3116677c084015e07d4e029329ae03f9073e28b6`. This register records the candidate implementation, each retained specialized owner, its scope and release/bound. “Retained” is an explicit disposition, not deferred mandatory migration. Source and focused checks identify the current implementation; full release qualification is recorded separately in the ticket.

“Adopted” describes source ownership, with qualification recorded separately. The published #1979 finite command-query contract is available; it is not a pending prerequisite. Home, Artifacts, Planner and Workspaces Changes now use host-retained command owners. Account status, project sync and devices use canonical account/origin service owners shared by native and extension consumers; Performance uses its window's monitoring controller. Their lifetime follows the actual owning controller and active view membership, including retained project workbenches and recreated guests. Presentation preferences reuse the common readonly host projection and the existing captured, ordered persistence owner. New service-query and controlled DiffViewer APIs must be delivered in an independently valid support PR and published before the consumers' registry qualification. Source availability alone does not clear that gate.

All finite query identities include runtime, account ID/origin, project and extension. The SDK root defaults to 128 inactive owners; the dashboard configures 512 for its combined ten-project native/catalog/editing workload. Normal least-recently-used eviction includes unread descriptors. Active observations, entered reads and required writes are protected; an unobserved read settling restores the inactive bound. Different domain bounds are stated below. Store/cache lifetime never grants authorization.

See the [author contract](../../guides/extensions/0010-shared-state-and-project-lifetimes.md), [stream contract](0021-stream.md), [diff recovery decision](../../adrs/0140-temporary-diff-watch-recovery.md) and [Sessions recovery decision](../../adrs/0141-temporary-session-metadata-recovery.md).
