# Skills

Open **Skills** in the project navigation footer. Select a skill in the sidebar to read its instructions, metadata, and supporting files. **Info** shows the skill's metadata; **Files** opens its file tree. The viewer is read-only.

The browser shows the project's resolved skill catalog, including skills contributed by enabled extensions. Skill storage and installation into agent folders remain host services.

Agents use the same catalog:

```sh
pst pstdio.pstdio-skills list --json
pst pstdio.pstdio-skills read --name create-pstdio-extension --json
```
