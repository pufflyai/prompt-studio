# Installing Extensions

Track extension installation from the puzzle icon in the status bar. Setup, marketplace, local-folder, upgrade, and harness package installations use the same host queue.

Open an extension name to inspect its page. A completed item shows a checkmark. A failed item shows its error and a Retry action.

The widget is visible by default. Change **Settings → Developer tools → Installing Extensions** to hide or show it. Hiding the widget does not stop installation. This setting is saved for your user across projects.
